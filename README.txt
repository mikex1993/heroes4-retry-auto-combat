Heroes IV: Retry Auto Combat
=============================

This mod allows you to reject a Quick Combat result and immediately replay the same battle manually.

REQUIREMENTS
------------

- Heroes of Might and Magic IV Complete
- Heroes IV Resolution Mod

Tested on the GOG version of Heroes IV Complete 3.0

Resolution Mod download:
http://h4.heroes.net.pl/uploaded/Download/H4ResMod_1.02.exe


INSTALLATION
------------

1. Install the Heroes IV Resolution Mod.

2. Copy the included files into your Heroes IV installation directory:

   mods\retry_auto_combat.mod

   Data\layers.dialog.Combat_results.h4d

3. Keep the original folder structure.

Your Heroes IV directory should look like this:

Heroes IV
├─ heroes4.exe
├─ DDRAW.dll
├─ mods
│  └─ retry_auto_combat.mod
└─ Data
   └─ layers.dialog.Combat_results.h4d

4. Start Heroes IV normally.


HOW TO USE
----------

After Quick Combat finishes, the normal battle results window will appear.

✓ / OK
Accepts the Quick Combat result.

X / Esc
Rejects the Quick Combat result and immediately starts the same battle manually.


UNINSTALLATION
--------------

Delete:

mods\retry_auto_combat.mod

and:

Data\layers.dialog.Combat_results.h4d
